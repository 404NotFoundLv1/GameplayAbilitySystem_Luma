# Luma

Luma is a top-down fantasy action RPG project built with Unreal Engine 5.  
The game focuses on elemental magic combat, RPG progression, save systems, and UI implementation.

## Gameplay

The player controls a magic character in a top-down view, explores levels, defeats enemies, gains experience, and unlocks or upgrades abilities.  
Combat is based on elemental skills such as fire, lightning, and arcane magic.

## Implemented Features

- Top-down click-to-move gameplay
- Elemental ability system
- Fire, Lightning, Arcane, and Passive abilities
- Ability upgrades with damage, cooldown, cost, duration, and radius changes
- RPG attribute system
- Enemy combat encounters
- Save slot system
- Checkpoint and load system
- Level transition system
- Minimap HUD
- Main menu, settings menu, credits, attribute menu, and ability menu
- Chinese UI and ability text localization
- Packaged build support
